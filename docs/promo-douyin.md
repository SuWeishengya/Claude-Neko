**标题：给你的终端装一只猫，它会告诉你 Claude 在想什么 🐱**

---

**文案：**

谁家写代码还没个小助理呢？我在 Claude Code 里养了一只小橘猫 🐱

它会实时盯着 Claude 的状态：
💭 思考时——猫也在皱眉思考
⌨️ 写代码时——猫在疯狂打字
🛠️ 执行工具时——猫在盯着屏幕看
😴 闲置太久——猫直接睡着了 zZz...
👍 任务完成——猫会开心跳跃！

最爽的是审批框直接画在猫身上，不用切回终端就能看到等审批。

🐱🐱 开多个终端窗口？每个 Claude 会话自动生一只猫！左边橘猫在写代码，右边蓝猫在调 Bug，互不干扰，窗口自动错开排排坐。`claude -c` 继续同一会话时还是同一只猫，不会错乱。

6 种颜色随便换，橘蓝粉灰黑白全都有，右键一秒切换。
